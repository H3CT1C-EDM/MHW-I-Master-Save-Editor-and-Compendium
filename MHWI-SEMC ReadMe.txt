Back up your save. Close the game and copy your original 'SAVEDATA1000' somewhere outside the Steam save folder. 
For Steam, the usual location is <Drive>\userdata\\582010\remote\SAVEDATA1000

Extract the download to a writable folder. Keep the release files together and ignore the included MHW-I Save Editor and Master Compendium.ink shortcut since it probably won't work since it was created on my local machine. 

Open the files folder and click launch.cmd to launch. You can open Guides right away but need to load a save to do much else. 
Windows will flag the file as unsafe, but click "Run anyway" to launch. 
(The editor uses Powershell at the moment, which is the cause of the flag; but you don't need to give it admin access and there is nothing malicious in the code. Feel free to scan everything! <3)

To edit a save, click 'Open Save', choose your PC Iceborne save (Usually <Drive>\userdata\65228156\582010\remote), and select the intended character slot. 
Make a small edit first and review the preview where available.
Click 'Save As' and give the edited copy a new name. With the game closed, keep your original backup and place the edited copy in the active save folder as 'SAVEDATA1000'.

When you’re ready to test it. Launch the game and verify the change on the intended character. 
A successful export confirms the file was written; only an in-game reload confirms the result you wanted.

For optional mods or plugins, select the game folder containing 'MonsterHunterWorld.exe' and use Game Data Exports with the game closed.
